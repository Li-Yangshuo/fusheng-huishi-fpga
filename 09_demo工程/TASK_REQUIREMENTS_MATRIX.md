# 第 4 项：基础 Demo 与性能验证

本包仅整理题面第 4 项。附件截图中的其他基础/高阶条款不作为这份 Demo 的范围。

| 要求 | Demo 实现 | 现有证据/边界 |
|---|---|---|
| 提供基础测试 Demo，展示实时风格化效果 | 随包 Ti60F225 工程和 BIT；KEY1 切入原画/风格对比 | RTL/模型/DDR BFM/HDMI 扫描联合仿真通过；现场显示需下载 BIT 复核 |
| 屏幕叠加当前 FPS | OSD 显示由实际推理完成事件统计的 FPS | OSD RTL 与 C/CPU 联合仿真有记录；不以 60Hz HDMI 刷新率代替推理帧率 |
| 640×480 下稳定达到 15fps 以上 | 本版图像链路按 1280×720 运行，分辨率高于题面基础尺寸 | 固定风格仿真稳态约 30.10fps；不是 640×480 实板实测，也不是持续实板 FPS 验收 |

现场报告只需展示风格画面和真实 OSD FPS，并记录观察时长、FPS 范围、BIT 哈希。若只有仿真记录，应称“仿真达到”，不可写成“实体板已稳定达到”。
