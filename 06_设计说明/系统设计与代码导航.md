# 浮生绘世——实时风格化渲染系统

基于Ti60F225的MIPI摄像头采集、FPGA定点CNN、DDR帧管理、HDMI显示和局域网交互。主线三风格为像素海报、水墨、霓虹；玻璃与漫画由另一双风格实现提供。各FPGA项目保留独立XML、约束、初始化文件和BIT。

## 数据和控制

~~~mermaid
flowchart LR
  CAM[SC431HAI] --> MIPI[MIPI D-PHY / CSI-2]
  MIPI --> PRE[RAW解码 / Debayer / Resize / 白平衡]
  PRE --> CAP[帧边界检查 / 帧ID]
  CAP --> DDR[(DDR多槽帧缓存)]
  DDR --> READ[AXI读取 / 池化]
  READ --> CNN[行融合INT8卷积 / 定点归一化 / 激活]
  CNN --> WRITE[AXI写回 / 完整帧提交]
  WRITE --> DDR
  DDR --> DISPLAY[原图结果配对 / 四布局 / OSD]
  DISPLAY --> HDMI[1280×720 HDMI 60Hz]
  DISPLAY --> ETH[网络抽头 / UDP]
  ETH --> PC[电脑接收与网页服务]
  PC --> PHONE[手机浏览器]
  KEYS[KEY1布局 / KEY2风格] --> CPU[RISC-V C控制]
  PC --> CPU
  CPU --> CAM
  CPU --> CNN
  CPU --> DISPLAY
~~~

RISC-V版本的C负责配置和调度，硬件负责卷积与像素搬运。CNN使用三行池化缓存、局部隐藏通道向量和输出行，不把层间特征整帧回写DDR。DDR租约和帧ID贯穿采集/推理/显示，不完整或AXI响应错误帧不得发布。

完整帧接口1280×720；像素海报内部CNN160×90，水墨/霓虹320×180，结果恢复到完整帧。显示预览640×360再按布局放大。输出分辨率、内部CNN网格和预览网格分别表述；HDMI扫描60Hz不是每秒60个新推理结果。

## 布局和风格

KEY1=P14循环原画全屏→同场景左原右渲染→渲染全屏→左右完整同场景对照；最后一种每侧640×720，纵向拉伸便于展示。M7 KEY2=N14循环像素海报→水墨→霓虹，KEY3=A3为同功能输入；玻璃漫画版本KEY2切换两风格。引脚以各peri.xml为准。

M7绑定TinyInk v1；水墨v2含不同前后处理，独立保留。五风格示例资料可能采用水墨v2，实际映射以工程参数绑定为准。M7上位机控制ID为0/1/2，玻璃/漫画由专用BIT展示，五种不是同时部署在一个BIT。

## RISC-V实现

firmware/main.c、startup.S、linker.ld、catalog.h分别负责业务、启动、内存布局和参数表。自定义RV32I管理核支持固件使用的machine CSR、外部IRQ与mret。text4544字节、boot RAM8192字节、栈保留768字节。

启动：OSD→166项相机配置及ACK检查→1152个32位参数字→部署完整确认→中断安装和使能→允许采集→轮询按键/网络并更新FPS。失败关闭采集写软件状态码；运行后锁住参数写口，防止混权重。

参数RAM为63×512位权重与9×512位偏置。三个风格共用融合核，选择bank和shift；乘积、累加、量化分级。RISC-V实现资源：XLR53623/60800，RAM10 250/256，DSP66/160；最差setup+0.425ns，hold+0.026ns。

## FPS和图像

FPS取100MHz域真实完成事件的8个间隔，显示0.1fps；断流1秒归零，不人为随机波动。C读计数生成16字符，硬件按帧叠加。白平衡为原图与风格输入共享前处理；展示提亮作用于显示，不修改训练权重。

## 电脑和手机

FPGV2 UDP带帧ID、左右通道及分包信息；protocol.py重组完整帧，server.py提供网页。左右按帧身份配对，避免半帧或旧新帧混合。网络为双640×360 RGB565、设计15fps，与HDMI及推理帧率独立。

按钮、语音“切换风格”和大幅挥掌进入统一命令接口，带序号下发板端并接收状态回执。语音由电脑离线识别，手势分析接收画面；手机通过同局域网浏览器访问电脑服务。无需公网，支持独立画面与截图保存，网络预览不叠加HDMI FPS文字。

## 模型统计

形状OIHW，参数数含权重/偏置；字节数按INT8权重+INT32偏置。额外BIN资产另列，均不含激活缓存和视频DDR。

| 模型 | 卷积形状OIHW | 参数数 | 权重偏置字节 | 额外BIN字节 |
|---|---|---:|---:|---:|
| PixelPoster v1 | 16×3×3×3 → 16×16×1×1 → 3×16×1×1 | 771 | 876 | 0 |
| TinyComic v1 | 8×4×3×3 → 8×1×3×3 → 8×8×1×1 → 3×8×1×1 | 475 | 556 | 256 |
| TinyGlass v1 | 8×4×1×1 → 8×8×1×1 → 3×8×1×1 | 139 | 196 | 12288 |
| TinyInk v1 | 8×1×3×3 → 8×8×1×1 → 1×8×1×1 | 161 | 212 | 0 |
| TinyInk v2 | 8×2×1×1 → 8×8×1×1 → 1×8×1×1 | 105 | 156 | 768 |
| TinyNeon v1 | 8×1×3×3 → 8×8×1×1 → 3×8×1×1 | 179 | 236 | 0 |

训练：程序化风格标签→浮点CNN→BN折叠→QAT→整数参数及金标。部署acc=sum(uint8×int8)+int32_bias，加舍入项、算术右移、饱和0–255。BN固定均值方差折叠入W/B，不逐帧算动态IN。玻璃几何ROM、漫画边缘/调色板、水墨v2纸色查表属于对应定点合同。

## 验证记录读法

用户实际演示确认电脑、手机和风格切换正常。RTL回归验证整数输出、帧配对、编码、寄存器和C执行；PNR报告描述资源/时序。RISC-V联合仿真采用实际编译C、CPU、参数RAM、行为I2C从机、DDR BFM及720p扫描；12帧对应12结果和12次ISR。显示编码独立覆盖12种模型/布局组合。保留NACK、时钟停滞、AXI异常、参数保护和同拍事件优先测试。仿真数值按仿真记录，不转述为实板测量。
