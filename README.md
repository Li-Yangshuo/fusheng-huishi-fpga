# 浮生绘世——赛题一源码与实现材料

提交内容包括M7三风格、RISC-V C软硬协同、玻璃/漫画与单玻璃实现、电脑及手机网页、训练量化模型、原理说明和验证记录。先阅读07_设计说明/系统设计与代码导航.md；构建与寄存器说明在同目录。

每个FPGA目录包含独立project与BIT。Efinity入口为project/structure/board_r6/project/ti60f225_oob.xml；不要跨目录混用RTL、约束、参数和BIT。对应BIT及SHA见BITSTREAMS.json。

M7三风格为像素海报、水墨、霓虹；玻璃和漫画由双风格版本提供。电脑上位机、手机网页及风格切换已由团队实际测试确认可用。RTL、软件和实现记录保留各自的测试方法，性能定义请参阅设计说明。

代码包不包含第三方开发工具安装程序、虚拟环境、原始训练图片集、仿真波形、可再生缓存及展示视频。模型参数、几何ROM、逐层金标、IP和外设依赖均保留。演示视频作为独立附加文件。

完整性校验：python -X utf8 VERIFY_PACKAGE.py。
